ACowork Mobile · IM 形态 v1

交互设计稿 — Desktop App 的移动端子集。定位：便携终端，v1 只做基础对话控制。 底部四栏对应 Desktop 左侧导航栏（Chat / Projects / Docs / Settings），Harness 与 Extensions 不上 App 端。

如何操作（原型手势）

  • 点击底部 聊天 / 项目 / 文档 / 设置 切换一级页面
  • 点击会话/条目进入详情；详情页右滑返回上一级
  • 聊天页左滑滑出 Agent 设置抽屉（= Desktop 右侧工作区）
  • 长按会话行 → 操作菜单（启动/停止/删除等）
  • 工作区文件树只有 Add to Chat，无 Monaco 预览

与 Desktop 的对应关系

  • 聊天列表 = AgentList + UserList 合并为一个 IM 会话流
  • 聊天抽屉 = RightPanel（Status / Workspace / Memory / Tools / Setup / Debug）
  • 项目 = ProjectsView（侧栏 → 看板 → 任务抽屉，三级列表）
  • 文档 = DocsView（目录树 → 文档，审阅队列独立入口）
  • 设置 = SettingsPage（Profile / General / Appearance / Gateway 四个二级页）

能力边界（v1 明确不做）

  • 文件预览 / Monaco 编辑器 → 只保留 Add to Chat
  • DevMode 断点调试（Desktop Debug tab）→ 不上 App
  • Git 状态条（ADR-078）→ 不上 App
  • Agent 创建 / 安装 / 克隆 / 发布（Desktop AgentList 右键菜单）→ 不上 App
  • Provider / API Key / MCP / Embedding（Harness）→ 不上 App

设计决策要点

  • 一级只有 4 栏：IM 心智里"更多"会稀释，PM/Doc 作为平级频道
  • 左滑 = 上下文面板：不侵入输入区，与微信"按住说话"侧滑一致
  • 右滑 = 返回：仅在非一级页生效，底部 Tab 永不右滑退出
  • 列表即真相：PM 看板列在手机上降级为横向 chip 筛选
