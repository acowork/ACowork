## What to cut

| Cut | Keep instead |
|-----|-------------|
| Survey results and market comparisons | the one conclusion drawn from them |
| Step-by-step derivation of a conclusion | the conclusion, plus one sentence on why |
| Restating a decision already stated | state it once |
| Illustrative examples / worked walkthroughs | drop unless the reader cannot use the rule without them |
| Aspirational or hedged prose | the committed decision |
| Emotional or rhetorical framing | drop |

## What never to cut

| Keep |
|------|
| Every decision and sub-decision, with its number |
| Every threshold, port, byte count, percentage, and timeout |
| Every file path, config key, and identifier (verbatim per GLOSSARY Rule 0) |
| Every table row that carries a distinct fact |
| Every MUST / MUST NOT / SHOULD constraint |
| The status, date, and decision makers |
| Rejected alternatives and why they were rejected |
| Upside / downside / rollback, when the source lists them |

**Target length: roughly 50–100% of the Chinese source.** A document that lands
well below 50% has almost certainly lost a decision; one above 100% usually means
narrative was carried over instead of being cut.
